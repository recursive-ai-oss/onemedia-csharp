# Speed, memory and I/O rows, 0.8: arm64 (Apple M2)

Method: [bench.md](../bench.md). Ratio = our median / the fastest managed comparator's median on the same file or workload (below 1.00× is faster); the gate is a geometric mean ≤ 1.00× overall and no row above 1.25×. Rows without a managed comparator pass and show our absolute times. Native tools are information.

## Machine and versions

- Host: arm64-mac; Apple M2; 8 logical cores; macOS 27.0.1 Arm64; ISA neon crc32 aes dotprod; runtime 10.0.11 (.NET 10.0.11); storage of the corpus: local NVMe/SSD, every file read once before its rows, so it is in the page cache for all implementations.
- Packages as restored: SharpMP4 0.3.2; RecursiveAI.OneAudio 1.7.0; MetadataExtractor 2.9.3; TagLibSharp 2.3.0.0; z440.atl.core 7.19; Matroska 0.0.12; LibSE (Subtitle Edit core) 5.3.0 and SubtitlesParser 1.5.1 for the subtitle rows.
- Native tools (information): ffmpeg version 8.0 Copyright (c) 2000-2025 the FFmpeg developers; MP4Box - GPAC version 26.07-revrelease; mkvmerge v103.0 ('The Darkness') 64-bit; MediaInfo MediaInfo Command line,; ExifTool 13.60.
- Method: one fresh process per (row, implementation, file); cold first run recorded in the Note column (information only, not gated); warm-up of at least 30 runs and 1.5 s; 3 samples (managed) and 3 runs (tools, once over 1 GiB); median reported.
- SDK 10.0.400, built Release, warnings as errors.
